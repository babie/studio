# Bump pnpm Deps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `apps/claude-app-server` の pnpm 依存を全て最新版へ更新し、`GHSA-p7fg-763f-g4gf` (moderate) を解消する。

**Architecture:** `pnpm -r update --latest` で workspace 全体を一括更新する。Elixir/Nix 側は今回スコープ外。全変更を `chore/bump-deps` ブランチに 1 コミットでまとめる。

**Tech Stack:** pnpm workspace, TypeScript (`tsc`), Vitest, Oxlint, Oxfmt, `@anthropic-ai/claude-agent-sdk`, valibot, commander, `@praha/byethrow`.

---

## Background

### `pnpm outdated` 出力 (Phase 0 時点)

| パッケージ | 種別 | 現行 → 最新 | semver |
|---|---|---|---|
| `@anthropic-ai/claude-agent-sdk` | dep | 0.2.138 → 0.2.140 | patch |
| `@praha/byethrow` | dep | 0.11.1 → 0.11.2 | patch |
| `vite` | dev | 8.0.11 → 8.0.12 | patch |
| `vitest` | dev | 4.1.5 → 4.1.6 | patch |
| `@types/node` | dev | 25.6.2 → 25.7.0 | minor |
| `oxlint` | dev | 1.63.0 → 1.64.0 | minor |
| `oxfmt` | dev | 0.48.0 → 0.49.0 | minor |

すべて **minor / patch** で、メジャー bump は無い。

### 既知の脆弱性

- `GHSA-p7fg-763f-g4gf` — `@anthropic-ai/sdk` (`@anthropic-ai/claude-agent-sdk` の transitive dep) の `>=0.79.0 <0.91.1` に Insecure Default File Permissions 問題。`@anthropic-ai/claude-agent-sdk` を 0.2.140 に上げれば transitive 解消されるはず。直接効果が無ければ `pnpm.overrides` で対応。

### サードパーティ scanner の見送り

当初 `pnpx supply-chain-attack` を実行する案があったが、scanner 自体が npm 公開 24時間以内・maintainer 1名・新規アカウントというリスクプロファイルだったため**実行しない**。built-in の `pnpm audit` のみを使う。

## Task 1: Verify baseline green on main

**Goal:** bump 前の現状が green であることを記録する。bump 後に何かが赤くなったら「bump が原因」と切り分けできる。

**Files:**
- Read: `apps/claude-app-server/package.json`
- 作成しない

- [ ] **Step 1: 作業ディレクトリへ移動**

```bash
cd /workspace/apps/claude-app-server
```

- [ ] **Step 2: 依存をインストール (lockfile 厳格に従う)**

```bash
pnpm install --frozen-lockfile
```
Expected: `Done in ...` で終了、依存の差分なし。

- [ ] **Step 3: 型チェック / ビルド**

```bash
pnpm build
```
Expected: `tsc` がエラーなく終了、`dist/bin.js` が出力されチェックマーク付き実行権限になる。

- [ ] **Step 4: テスト**

```bash
pnpm test
```
Expected: vitest が全件 pass で終了 (exit code 0)。

- [ ] **Step 5: Lint**

```bash
pnpm lint
```
Expected: oxlint が 0 warning / 0 error で終了。

- [ ] **Step 6: Format check**

```bash
pnpm format:check
```
Expected: oxfmt が差分無しで終了 (exit code 0)。

- [ ] **Step 7: audit (既知の脆弱性をベースライン記録)**

```bash
pnpm audit 2>&1 | tee /tmp/audit-before.txt
```
Expected: `GHSA-p7fg-763f-g4gf` (moderate, `@anthropic-ai/sdk`) が出る。
出ない場合は脆弱性 DB が更新されたか lockfile が既に解消済の可能性 → ユーザに確認。

- [ ] **Step 8: 結果を保存 (この後の比較用)**

`/tmp/audit-before.txt` の内容を Task 3 と比較するので残しておく。コミット不要。

このタスクは何もコミットしない (現状確認のみ)。

## Task 2: Create branch and bump deps

**Goal:** `chore/bump-deps` ブランチ上で `pnpm update --latest` を実行し、package.json と pnpm-lock.yaml の差分を作る。

**Files:**
- Modify: `apps/claude-app-server/package.json`
- Modify: `pnpm-lock.yaml` (リポジトリルート)

- [ ] **Step 1: ブランチ作成**

```bash
cd /workspace
git switch -c chore/bump-deps
```
Expected: `Switched to a new branch 'chore/bump-deps'`

- [ ] **Step 2: 全パッケージ更新 (workspace 全体に対し latest へ)**

```bash
pnpm -r update --latest
```
Expected: 上の表 7 件が更新される。`Done` で終了。

注意: `pnpm -r` でも対象は実質 `apps/claude-app-server` のみ (ルートと `apps/symphony` には pnpm deps が無い)。

- [ ] **Step 3: package.json と lockfile の差分確認**

```bash
git diff -- apps/claude-app-server/package.json pnpm-lock.yaml | head -200
```
Expected:
- `package.json` の各 caret range が新バージョンに書き換わっている  
  (例: `"@anthropic-ai/claude-agent-sdk": "^0.2.140"`)
- `pnpm-lock.yaml` で対応する `resolution`/`integrity` が更新されている

unexpected な依存 (新規追加 / 削除) が現れたら停止してユーザに報告。

このタスクはまだコミットしない (Task 3 の検証が通ってからまとめてコミット)。

## Task 3: Verify post-bump and commit

**Goal:** bump 後も build / test / lint / format / audit が全部通ることを確認、脆弱性も解消していることを確認してからコミット。

**Files:**
- Modify: `apps/claude-app-server/package.json` (必要なら `pnpm.overrides` を追加)
- Read のみ (基本)。修正があれば Step 6 以降を参照。

- [ ] **Step 1: クリーンインストールで lockfile 整合性確認**

```bash
cd /workspace/apps/claude-app-server
pnpm install --frozen-lockfile
```
Expected: `Done` で終了。`ERR_PNPM_OUTDATED_LOCKFILE` が出たら lockfile 更新漏れ → `pnpm install` を `--frozen-lockfile` 無しで一度走らせる。

- [ ] **Step 2: ビルド**

```bash
pnpm build
```
Expected: tsc エラー 0 で終了。型エラーが出たら **停止してユーザに報告** (新バージョンで型が変わった可能性)。

- [ ] **Step 3: テスト**

```bash
pnpm test
```
Expected: 全件 pass。失敗があれば失敗ケースをユーザに見せて指示を仰ぐ。

- [ ] **Step 4: Lint**

```bash
pnpm lint
```
Expected: 0 warning / 0 error。新 oxlint で新ルールが有効になった場合は警告が出得る。出た場合はユーザに見せて (a) 抑制 (b) 修正 を相談。

- [ ] **Step 5: Format check**

```bash
pnpm format:check
```
Expected: 差分なし。oxfmt 0.49.0 で format ルールが変わっていれば差分が出る → `pnpm format` を流して再確認。

- [ ] **Step 6: Audit で GHSA-p7fg-763f-g4gf 解消確認**

```bash
pnpm audit 2>&1 | tee /tmp/audit-after.txt
diff /tmp/audit-before.txt /tmp/audit-after.txt || true
```
Expected:
- `/tmp/audit-after.txt` で `No known vulnerabilities found` または `GHSA-p7fg-763f-g4gf` が消えている

もしまだ残っていたら、`@anthropic-ai/claude-agent-sdk` が patched な transitive を pin できていない → `apps/claude-app-server/package.json` に `pnpm.overrides` を追加して再 install:

```json
{
  "pnpm": {
    "overrides": {
      "@anthropic-ai/sdk@>=0.79.0 <0.91.1": ">=0.91.1"
    }
  }
}
```

その後 Step 1 から再実行。

- [ ] **Step 7: コミット**

```bash
cd /workspace
git add apps/claude-app-server/package.json pnpm-lock.yaml
git commit -m "$(cat <<'EOF'
chore(claude-app-server): bump deps to latest (minor/patch)

Resolves GHSA-p7fg-763f-g4gf (transitive @anthropic-ai/sdk file
permissions issue) by bumping @anthropic-ai/claude-agent-sdk to 0.2.140.
EOF
)"
```

Expected: 1 commit 作成。

`pnpm.overrides` を追加した場合は package.json の差分も含まれる。
