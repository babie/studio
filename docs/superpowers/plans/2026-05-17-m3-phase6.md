# M3 Phase 6: 並列実行 / Retry / Edge cases パリティ Implementation Plan — Overview

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Each part file contains the actual task content with `- [ ]` checkbox steps.

**Goal:** Port `apps/symphony/lib/symphony_elixir/orchestrator.ex` (1,826 LoC) + `agent_runner.ex` + `log_file.ex` to `apps/conductor` as a parallel scheduler with retry/backoff, stall detection, blocker/priority/assignee filters, robust turn-end detection, and a pino-based JSON file logger.

**Architecture:**
1. **Scheduler** (new): a long-lived class that owns `running` / `claimed` / `retryAttempts` Maps + a `p-queue` (concurrency = `agent.max_concurrent_agents`) + a `pollTimer`. Drives a pump cycle each tick: `reconcileRunning()` → `fetchCandidates()` → `selectDispatchable()` → `queue.add(dispatchIssue)`.
2. **dispatch-filter** (new, pure): `sortByPriorityThenCreatedAt`, `isBlockerSkippable`, `selectDispatchable`. Lifted out of Scheduler for easy testing.
3. **retry-policy** (new, pure): `continuationDelay()` returns 1,000ms; `failureDelay(attempt, maxBackoffMs)` returns `min(10_000 × 2^min(attempt-1, 10), maxBackoffMs)` — symphony verbatim.
4. **Backend session** gains `exitPromise: Promise<{code, signal}>`. `runTurn` internally races `turn/completed` / `exitPromise` / `abortPromise` so subprocess crashes mid-turn surface as `session-exited-mid-turn` Failures.
5. **AgentRunner** is per-issue async function (queued via `p-queue`). Resolves on normal session end; rejects on session-exit-mid-turn / abort / tracker / workspace / prompt error. Scheduler maps resolution kind → `continuation_retry` or `failure_retry`.
6. **file-logger** (new): pino + pino-roll size-based wrap rotation (10MB × 5 files). JSON output. `CONDUCTOR_DEBUG=1` swaps to pino-pretty stderr.
7. **Issue domain** gains `priority`, `createdAt`, `assigneeId`, `assignedToWorker`, `blockedBy` (populated by Linear + GitHub + Memory adapters).

**Tech Stack:** Phase 5 stack + new deps `p-queue`, `p-retry`, `pino`, `pino-roll`, `pino-pretty`.

**Branch:** `feat/m3-phase6` (create at start of Pre-flight; user requested branch, not worktree).

**Spec:** [`docs/superpowers/specs/2026-05-17-m3-phase6-design.md`](../specs/2026-05-17-m3-phase6-design.md)
